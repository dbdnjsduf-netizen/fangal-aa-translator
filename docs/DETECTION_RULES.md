# 문자 감지 규칙 검토 기록

## 목표

자동 감지는 일본어 문자가 있는지 여부만 보지 않는다. Shift-JIS AA에서는 `ノ`, `へ`,
`ハ`, `つ`, `二`, `人` 같은 문자가 얼굴·머리카락·선으로도 자주 사용되므로 다음 증거를
결합한다.

1. 히라가나 어절, 한자+가나 혼합, 의미 있는 가타카나 어절 같은 어휘 증거
2. 말풍선의 방향이 올바른 좌우 경계
3. 후보 좌우의 공백과 위아래 문맥
4. 기호 대비 일본어 문자 비율과 AA 모양 문자 반복
5. 사용자가 저장한 금지항목과 수동정규식의 긍정·부정 예시
6. 후보에 직접 연결된 AA 덩어리의 행·폭·구조 문자 비율과 주변 2차원 점유 형태

## 일반 가로 대사

- 어휘 증거가 강하거나 6자 이상인 대사는 위아래 줄이 붙어 있어도 허용한다.
- 짧고 어휘 증거가 약한 후보는 양쪽에 최소 공백이 있거나 정상 말풍선 경계 안에 있어야 한다.
- 검증된 말풍선 박스 안에서는 한자 1자와 가나 1자가 `!?` 같은 문장 부호와 함께
  쓰인 짧은 대사도 허용한다.
- 박스 밖의 4자 이하 후보가 여러 방향의 AA 획에 조밀하게 둘러싸여 있으면 캐릭터
  그림 조각으로 보고 자동 선택하지 않는다.
- 반복된 AA 모양 문자, 얼굴 괄호 안의 짧은 조각, 기호가 문자보다 많은 후보는 제외한다.
- 같은 한자가 4회 이상 이어지거나 장문의 반각 가타카나가 반복되거나 한자·반각 가나·ASCII
  기호가 비문장 형태로 뒤섞이면
  문자 질감 후보로 분류한다. 반각 문장은 주변의 큰 AA 덩어리와 연결된 경우에만 제외한다.
- `二·ニ·ﾆ·一·ー`가 선·점과 섞인 경우에는 NFKC 정규화 후 구조 문자만 다시
  비교해 완전 반복이 아니어도 가로획 AA로 제외한다.
- 단문이라도 `おい`처럼 서로 다른 히라가나가 이어지거나 `危険！`처럼 구두점이 있는
  의미 단위는 허용한다.

## 세로쓰기

- 파이프형·화살표형 말풍선은 각 행의 좌우 경계, 열 위치, 행 연속성을 함께 확인한다.
- 멀리 떨어진 외곽 파이프만으로는 말풍선으로 인정하지 않으며, 경계 사이 한 행에 AA
  기호가 과도하면 해당 문자 슬롯을 제외한다.
- 자동 세로 열은 중간 행을 건너뛰지 않는 연속 슬롯이어야 한다.
- 자유형 말풍선은 글자 왼쪽과 오른쪽 모두에 경계 문자가 있어야 한다.
- 자동 열의 전체 좌우 흔들림은 최대 6 표시 칸이고, 자유형 열은 행 사이를 2줄 넘게
  건너뛰지 않는다.
- 세로 열은 최소 3행 이상의 의미 있는 일본어로 성립해야 한다. 숫자와 구두점은 이미
  성립한 열의 문맥 문자로만 포함한다.
- 불규칙한 배치는 자동으로 억지 연결하지 않고 `세로수동`으로 명시적으로 지정한다.

## 사용자 규칙을 통한 보정

- 금지항목은 계속 완전 일치가 최우선이다.
- 추가로, 금지된 짧은 AA 조각과 편집거리·문자쌍이 매우 비슷한 약한 후보만
  `전체 선택`에서 제외한다.
- 자연스러운 장문에는 유사 패턴 학습을 적용하지 않는다.
- 수동정규식에 같은 유형의 긍정 예시가 있으면 금지 패턴의 유사 일반화를 취소한다.
- 금지·긍정 예시는 원문 유사도뿐 아니라 상하좌우 그림 배치 서명을 함께 비교한다.
- 확실한 대사는 자동 선택하고, 그림 가능성이 남은 항목은 표시만 유지하며,
  큰 연결 성분의 구조 문자는 그림으로 제외한다.
- 규칙을 삭제하면 해당 학습 제외도 즉시 제거된다.

## 남는 한계

한자 한두 글자만 있는 텍스트는 언어와 그림을 문자 자체로 완전히 구별할 수 없다.
자동 감지는 오탐 억제를 우선하며, 실제 짧은 표지·이름이 빠진 경우 `수동` 또는
`수동정규식`으로 추가하는 것이 안전하다.
